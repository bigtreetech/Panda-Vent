## Introduction
The Panda Vent is a plug-and-play smart upgrade for FDM printers. It automatically controls airflow, prevents hotend clogs, and keeps prints stable. Its top glass riser eliminates PTFE tube wear, while customizable RGB lighting adds style and functional feedback. Compatible with P1, P2, X1, X2, and most enclosed printers, the Panda Vent ensures uninterrupted printing and superior performance.


## Key Features
- **RGB Lighting
- **Customizable lights for style and feedback
- **Automatic Vent Control
- **Smart airflow adjustment for stable printing
- **Prevents Hotend Clogs
- **Ensures uninterrupted prints
- **Top Glass riser eliminates PTFE rubbing
- **Plug & Play Upgrade
- **Compatible with P1/P2/X1/X2 and more
