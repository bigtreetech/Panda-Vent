## Material Selection

     
Main Frame: 

- Any material with temprature resistance above 60C.

Recommended material:
- **ABS/CF/GF (https://biqu.equipment/products/biqu-carboncore25-carbon-fiber-reinforced?variant=41999303737442)
- **PETG/CF/GF (https://biqu.equipment/products/biqu-carboncore25-carbon-fiber-reinforced?variant=41999303770210)
- **PA/CF/GF (https://biqu.equipment/products/biqu-carboncore25-carbon-fiber-reinforced?variant=41999303802978)
- **ASA/CF/GF (Coming Soon)

********************************

Light Defuser: 

- This part requires transparancy for RGB effect, use any material that allows light to pass through, temperature resistance does not matter in this application

Recommended material:
- **PLA White (https://biqu.equipment/collections/filament/products/new-biqu-pla-hs-filament)
- **PLA Transparent (Coming Soon)
- **PETG Transparent (Coming Soon)
- **PC Transparent (Coming Soon)
