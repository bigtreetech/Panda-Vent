## 1. 产品简介

**Panda Vent** 是一款专为 FDM 3D 打印机设计的智能通风增高架。它可以实时监测打印状态，并自动控制风扇和灯光，让你的打印机更加智能、安静、清凉。

## 核心功能

- 🌈 **RGB 状态灯：**  
  使用 WS2812 LED 灯带实时显示打印机状态，包括空闲、准备中、打印中、暂停、已完成和错误状态，一眼即可掌握当前打印状态。

- 🌀 **智能风扇控制：**  
  支持 **自动模式** 和 **手动模式**。自动模式会根据打印机状态自动控制风扇；手动模式下可通过按键切换风扇开关。

- 🌡️ **增强散热：**  
  优化内部气流并主动排出热空气，有效帮助防止因腔体温度过高导致的喷嘴堵塞，并提升长时间打印的稳定性。

- 🏗️ **增高架设计：**  
  抬高顶部玻璃或 AMS 安装空间，显著减少 PTFE 管与顶部玻璃盖之间的摩擦，有助于降低管材磨损、摩擦噪音和打印失败风险。

- 📡 **MQTT 通信：**  
  通过本地 MQTT 协议与 Bambu Lab 打印机通信。无需云端连接，响应快速且稳定可靠。

- 🌐 **Web 管理界面：**  
  内置 Web UI，可通过任意浏览器配置 Wi-Fi、MQTT、灯光、风扇及其他功能。

- 🔄 **OTA 升级：**  
  支持通过 Web UI 进行固件升级，维护简单方便。

- 🔌 **自动识别 LED 灯带：**  
  可自动检测连接的是 1 组还是 2 组 LED 灯带：
  - **1 组灯带：** 16 颗 LED
  - **2 组灯带：** 27 颗 LED

  无需手动设置，即插即用。

## 适用场景

Panda Vent 适合以下用户：

- 需要更好的腔体散热或气流改善。
- 希望通过灯光直观查看打印机状态，而无需频繁查看打印机屏幕。
- 喜欢 DIY 智能外设，并希望将设备集成到现有 **Home Assistant** 或 **MQTT** 系统中。
- 想要优化 PTFE 管走线，减少摩擦噪音，并降低管材磨损。

## 2. 硬件概览

### 物理按键

| 按键 | 位置 | 功能 |
|------|------|------|
| **LED 按键** (GPIO 12) | 设备面板 | 单击：切换风扇开/关；长按（3秒）：切换自动/手动模式 |

| 手动模式 |

- 处于自动模式下，单击按钮会回到手动模式，并且立刻翻转扇叶
- 处于手动模式下，单机立刻翻转扇叶

| **BOOT 按键** (GPIO 0) | 设备侧面 | 长按（3秒）：恢复出厂设置 |

### 指示灯

| 状态 | LED 表现 |
|------|----------|
| **自动模式** | LED 常灭 |
| **手动模式** | LED 闪烁（0.5秒间隔） |

### 接口与灯组

- 支持 **1 组灯带**（16 颗 LED）或 **2 组灯带**（27 颗 LED）
- 设备会通过 ADC 电压自动检测当前插入的灯组数量，无需手动配置

## 3. 首次使用

### 步骤一：上电启动

1. 给 Panda Vent 通电，设备将自动启动
2. 首次启动时，设备会自动开启 **Wi-Fi 热点**（AP 模式）

### 步骤二：连接设备热点

1. 在手机或电脑上搜索 Wi-Fi，找到以 `Panda_Vent_` 开头的热点
2. 输入默认密码：**`987654321`**
3. 连接成功后，打开浏览器

### 步骤三：进入 Web 管理界面

1. 在浏览器地址栏输入：**`192.168.254.1`**
2. 或者在同一局域网下访问：**`http://PandaVent.local`**（需要设备已连接 Wi-Fi）
3. 首次打开会进入 **语言选择页面**

### 步骤四：选择语言

- 支持 **English** 和 **简体中文**
- 选择后点击 **下一步** 进入 Wi-Fi 配置

## 4. Wi-Fi 配置

### 连接家庭 Wi-Fi（STA 模式）

1. 在 Web 界面点击底部导航栏的 **Wi-Fi** 图标进入网络设置
2. 点击 **扫描** 按钮搜索附近的 Wi-Fi 网络
3. 从下拉列表中选择你的 Wi-Fi 网络
4. 输入 Wi-Fi 密码
5. 点击 **连接**
6. 连接成功后，页面会显示设备获取的 **IP 地址**

> ⚠️ **重要提示**：Panda Vent 和拓竹打印机必须连接到 **同一局域网**，才能正常通信。

### 设置主机名

- 默认主机名为 `PandaVent`
- 你可以自定义主机名，设置后可通过 `<主机名>.local` 访问设备
- 修改后点击 **设置主机名** 按钮保存

### 热点（AP）设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 热点开关 | 开启 | 可手动关闭热点以节省资源 |
| 热点名称 | `Panda_Vent_XXXX` | 后缀为设备 MAC 地址标识 |
| 热点密码 | `987654321` | 建议修改为自定义密码 |
| 热点 IP | `192.168.254.1` | 可自定义 |

## 5. 绑定拓竹打印机

### 准备工作

请确保以下条件满足：
- Panda Vent 已连接到 Wi-Fi
- 拓竹打印机已连接到 **同一局域网**
- 准备好打印机的 **SN 号** 和 **访问码**（Access Code）

### 获取打印机信息

- **SN 号**：在打印机设置 → 设备信息中查看
- **访问码（Access Code）**：在打印机设置 → 局域网模式中查看（8 位字符）
- **IP 地址**：在打印机网络设置中查看

### 绑定步骤

1. 在 Web 界面点击底部导航栏的 **打印机** 图标
2. 点击 **扫描** 按钮，设备会通过 UDP（SSDP 协议）自动发现局域网内的拓竹打印机
3. 从下拉列表中选择你的打印机（会自动填充 SN 和 IP）
4. 手动输入打印机的 **访问码**（Access Code）
5. 点击 **绑定** 按钮
6. 等待连接，成功后界面会显示连接状态

### 连接状态说明

| 状态 | 说明 |
|------|------|
| 已连接 | MQTT 连接成功，正常工作 |
| 连接中 | 正在尝试建立 MQTT 连接 |
| IP 错误 | 打印机 IP 地址不正确 |
| SN 错误 | 打印机 SN 号不匹配 |
| 访问码错误 | Access Code 不正确 |

## 6. RGB 灯效设置

点击底部导航栏的 **主题** 图标进入灯效配置页面。

### 6.1 灯光总开关

- **灯光开关**：总开关，控制所有 RGB 灯效的开启/关闭
- **警告覆盖**：开启后，当打印机出现高温等警告状态时，灯效会被警告灯效覆盖
- **跟随打印机模式**：灯效颜色和效果跟随打印机当前状态自动变化
- **跟随通风模式**：灯效颜色和效果跟随风扇状态变化
- **反转方向**：反转灯带的灯效流动方向

### 6.2 灯光模式

设备提供 **三种灯光模式**：

#### 模式一：简单模式（Simple Mode）

适合只想设置一种固定灯效的用户。

**可选效果：**

| 效果 | 说明 |
|------|------|
| 静态（Static） | 常亮，固定颜色 |
| 呼吸（Breathing） | 灯光缓慢渐亮渐暗 |
| 频闪（Strobing） | 灯光快速闪烁 |
| 水波（Wave） | 灯光如水波般流动 |
| 跑马灯（Marquee） | 灯珠依次点亮移动 |
| 色彩循环（Color Cycle） | 颜色自动循环变换 |
| 彩虹（Rainbow） | 彩虹渐变效果 |

**可调参数：**
- 🎨 **颜色**：点击颜色按钮打开 HSL 取色器，自由选择颜色
- 💡 **亮度**：0% ~ 100%，步进 5%
- ⚡ **速度**：0% ~ 100%，步进 5%（部分效果不支持速度调节）

#### 模式二：高级模式（Advance Mode / H2D）

为打印机的 **每个工作状态** 分别配置不同的灯效。

| 状态按钮 | 对应打印机状态 | 默认颜色 |
|----------|---------------|----------|
| 空闲 | 打印机空闲 | 白色 (FFFFFF) |
| 准备 | 下载/切片准备中 | 橙色 (F8A323) |
| 打印 | 正在打印 | 彩虹效果 |
| 暂停 | 打印暂停 | 白色 (FFFFFF) |
| 完成 | 打印完成 | 绿色 (00FF2A) |
| 报错 | 打印出错/报警 | 红色 (FF0000) |

每个状态都可以单独设置效果类型、颜色、亮度和速度。

#### 模式三：温度警告模式（Warning Hot Mode）

基于打印机温度状态显示灯效，分为 **安全** 和 **危险** 两个级别：

- 🟢 **安全状态**：绿色灯效，可选静态或频闪
- 🔴 **危险状态**：红色灯效，可选静态或频闪

每个级别都可以独立设置亮度和速度。

## 7. 风扇/电机控制（按键操作）

Panda Vent 的风扇支持两种工作模式：

### 自动模式（AUTO）

- **默认模式**，设备根据打印机状态自动控制风扇开关
- LED 指示灯 **常灭**
- 打印时自动开启排风，空闲时自动关闭

### 手动模式（MANUAL）

- LED 指示灯 **闪烁**
- 完全由用户手动控制风扇的开关

### 按键操作指南

| 操作 | 功能 |
|------|------|
| **LED 按键 单击**（自动模式下） | 切换到手动模式，并切换风扇状态（开↔关） |
| **LED 按键 单击**（手动模式下） | 切换风扇状态（开↔关） |
| **LED 按键 长按 3 秒** | 从手动模式切换回自动模式 |
| **BOOT 按键 长按 3 秒** | 恢复出厂设置（详见第 9 节） |

> 💡 **提示**：模式切换状态会自动保存到 NVS（非易失性存储），断电后重启会恢复上次的模式设置。

### 电机分组

设备支持 4 组电机通道（GROUP 1~4），每组电机配备：
- 独立的霍尔传感器用于位置检测
- 正转/反转 PWM 控制
- 渐变启动（防止电机突然启动产生冲击）

## 8. OTA 固件升级

### 升级步骤

1. 在 Web 界面点击底部导航栏的 **设置** 图标
2. 查看当前固件版本号
3. 点击 **固件升级** 按钮
4. 选择新的固件文件（`.bin` 格式，最大约 4.5MB）
5. 等待上传和烧写完成，界面会显示进度
6. 升级完成后设备自动重启

> ⚠️ **注意事项**：
> - 升级过程中 **请勿断电或断开网络**
> - 升级过程中 RGB 灯带会显示白色 OTA 动画提示
> - 如升级失败，设备会回滚到上一版本固件

## 9. 恢复出厂设置

### 方式一：物理按键

- **长按 BOOT 按键（GPIO 0）3 秒**，设备将清除所有配置并重启

### 方式二：Web 界面

1. 进入 **设置** 页面
2. 点击 **恢复出厂设置** 按钮
3. 确认弹窗中点击确定

### 出厂设置将清除以下内容：

- ✅ Wi-Fi 连接信息（STA 配置）
- ✅ 打印机绑定信息（SN、访问码、IP）
- ✅ RGB 灯效自定义配置
- ✅ 风扇模式偏好设置
- ✅ 语言设置
- ✅ 热点自定义配置

> 恢复出厂设置后，设备将重新进入初始配置流程。

## 10. 常见问题（FAQ）

### Q1：连接不上打印机怎么办？

**A：** 请检查以下几点：
1. Panda Vent 和打印机是否在 **同一局域网**
2. 打印机的 **局域网模式** 是否已开启
3. **访问码（Access Code）** 是否正确（注意大小写）
4. 打印机 **IP 地址** 是否正确（可在打印机端确认）
5. 尝试在 Web 界面重新扫描打印机

### Q2：灯带只亮了一部分？

**A：** 设备会根据 ADC 检测自动识别灯组数量：
- 1 组灯带 = 16 颗灯珠
- 2 组灯带 = 27 颗灯珠
- 如果未检测到灯带（电压为 0），灯效将不显示

请检查灯带连接是否牢固。

### Q3：按键没有反应？

**A：** 
- 按键有 5ms 的防抖处理，请确保按压到位
- 长按需要 **持续按住 3 秒** 才能触发
- 单击响应有约 300ms 的延迟（用于区分单击和连击）

### Q4：Web 界面无法访问？

**A：**
1. 如果通过热点连接：访问 `192.168.254.1`
2. 如果通过局域网连接：访问 `PandaVent.local` 或设备分配的 IP 地址
3. 确保浏览器和设备在同一网络
4. 尝试清除浏览器缓存后重试

### Q5：设备断电后配置会丢失吗？

**A：** 不会。以下配置会自动保存到 NVS（非易失性存储）中：
- Wi-Fi 配置
- 打印机绑定信息
- RGB 灯效设置
- 风扇模式偏好
- 语言设置

断电重启后会自动恢复所有配置。

### Q6：支持哪些拓竹打印机型号？

**A：** 理论上支持所有开启了局域网模式的拓竹打印机，包括但不限于：
- Bambu Lab P1P / P1S
- Bambu Lab X1 / X1 Carbon
- Bambu Lab A1 / A1 Mini
